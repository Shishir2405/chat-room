# Chat Room

A real-time chat application with typing indicators and message persistence.

**Stack:** React + Vite (client), Node.js + Express + Socket.IO (server), localStorage for client-side message history.

## Run Locally
- Server: `cd server && npm install && node server.js`
- Client: `cd client && npm install && npm run dev`

Open the client URL in two browser tabs to chat across sessions.
